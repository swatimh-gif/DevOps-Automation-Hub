.github/workflows/ci.yml

Every code push to GitHub executes the automated CI/CD workflow on an isolated Ubuntu runner:

Checkout: actions/checkout@v4 clones latest commit.
Python Setup: Sets up Python 3.11 with pip caching.
Testing: Runs flake8 linter and pytest tests/ -v.
Docker Build: Builds container image using docker/build-push-action@v5.
Container Smoke Test: Runs container and queries curl /health.
